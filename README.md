# 🚚 Simulador de Fretes

Aplicação web desenvolvida em **Java**, utilizando **JSP (JavaServer Pages), Servlets e Apache Tomcat**, com o objetivo de simular o cálculo de fretes a partir de informações fornecidas pelo usuário.

## 🎯 Sobre o projeto

O projeto foi desenvolvido como um trabalho facultativo, no contexto dos estudos de **Java para Web**, com o propósito de colocar em prática conceitos de desenvolvimento de aplicações web utilizando o ecossistema Java.

A aplicação permite informar os dados de uma entrega e obter o valor estimado do frete de acordo com os parâmetros selecionados.

## 🛠️ Tecnologias utilizadas

- **Java** — Linguagem de programação.
- **JSP (JavaServer Pages)** — Construção das páginas dinâmicas.
- **Servlets** — Processamento das requisições HTTP.
- **Apache Tomcat** — Servidor de aplicação web.
- **HTML/CSS** — Estruturação e estilização das páginas.

## ⚙️ Funcionalidades

- Inserção do peso da encomenda.
- Definição da distância de entrega.
- Seleção da modalidade de frete.
- Cálculo do valor final do frete.
- Exibição dos dados e do resultado da simulação.

## ▶️ Execução

Para executar o projeto, é necessário ter:

- JDK instalado.
- Apache Tomcat 10 ou superior.
- IDE ou editor de código compatível com Java.

Configure o projeto no Tomcat e inicie o servidor para acessar a aplicação pelo navegador.
